# A note to the judges

I’m Dani, and I’ve been building Patchriot on my own.

It runs a pre-penetration pass on a site you own: automated checks, agent-led investigation, evidence you can read and check. It does not replace a human researcher, and it is not trying to.

Next I want to do this on code, not only on live sites: hand it a repository, run it in a sandbox like NEAR’s Red SandBox. Nothing installed on your machine, nothing handed to someone else’s build box, the code visible only to you and whoever you approve, the model running where the host itself cannot read it.

## Try it yourself

**Every judge gets one free coupon** for a hosted black-box or grey-box assessment. I’ll share each code privately, sent from my own personal Twitter account (@dani_who_daniel)—not the project’s—so check the messages there and treat it as coming from me directly.

1. Sign in at [patchriot.net](https://patchriot.net).
2. Add a website you own and verify its domain. For grey-box testing, add a disposable test account.
3. Choose **Coupon → Enter a code** at checkout, confirm the scope and start. Your private report includes findings, evidence and coverage limits.

The [local setup guide](README.md#run-locally) covers all three repositories and can be handed to your own agent.

If any of this is where you would want to collaborate, reach out.

— Dani
